# אשף ה־API למורים

אתר סטטי בעברית שעוזר למורים להשיג מפתח API לכלי הוראה מבוססי בינה מלאכותית.
האתר לא מנפיק מפתחות, לא מבקש אותם ולא שומר אותם.

## הרצה במחשב שלכם
צריך להתקין [Node.js](https://nodejs.org). אחר כך, בתיקיית הפרויקט:

```bash
npm start
```

ופתחו בדפדפן את http://localhost:8080/ (לא פותחים את `index.html` ישירות, כי הדפדפן חוסם טעינת קובצי נתונים).
במחשב Windows אפשר גם ללחוץ פעמיים על `start.bat`.

## בדיקות
```bash
npm test
```

## קישורים לאשף
- `?tool=cardiac-simulator` — כלי שרשום ב־`data/tools.json`
- `?providers=gemini,groq` — כלי שאינו רשום; מפתח הכלי מצהיר על הספקים

## הוספת ספק
1. הוסיפו אובייקט ב־`data/providers.json` (שדה שלא ידוע: `not_verified`).
2. הוסיפו מדריך ב־`data/guides.json` ושייכו אותו בשדה `guideId`.
3. עדכנו `lastVerified` והוסיפו מקורות רשמיים.
4. הריצו `npm test`.

## הוספת כלי
הוסיפו אובייקט ב־`data/tools.json`. אל תסמנו `compatibilityVerified` בלי שבדקתם בפועל שהמפתח עובד בכלי עם הספקים שרשמתם.

## הקישור "רוצים להוסיף כלי שלכם?"
הקישור מוסתר כרגע. כדי להציג אותו, הכניסו כתובת https בשדה `submissionUrl` ב־`data/tools.json` (למשל טופס או כתובת Issues). `null` מסתיר אותו.

## פרסום ב־GitHub Pages
1. העלו את הקבצים ל־repository ב־GitHub (למשל בשם `api-wizard`).
2. ב־Settings ← Pages: Source = Deploy from a branch, Branch = `main`, Folder = `/ (root)`.
3. אחרי כדקה האתר זמין בכתובת `https://<שם-משתמש>.github.io/api-wizard/`.
4. כל שינוי שתעלו ל־`main` יתפרסם אוטומטית.

## לפני פרסום לציבור
המידע על הספקים נאסף מתיעוד ומאתרים ברשת ולא נבדק בהרשמה אמיתית מישראל. יש לבדוק ידנית לפחות את Gemini ו־Groq (כרטיס אשראי, אימות טלפון, מכסות) ולעדכן את הנתונים.
